MDPI-paper (authors: Rui Azevedo Antunes and Luís Brito Palma).

This repository contains the open edition of Nighttime Bed-Leaving Alert System and Fall-Prevention (NBLASFP) described in the MDPI paper titled "A New Hardware/Software Assistive Wi-Fi Device for Elderly Bed-exit Event at Night", which is under revision. The NBLASFP.aia file in the App folder opens in MIT App Inventor and contains the block-based code for the Android App.
